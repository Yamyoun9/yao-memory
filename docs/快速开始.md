# 快速开始

## 前提

- Python 3.10 或更高版本
- 已安装并启动 EverOS 服务
- LLM API Key（阿里百联 / DeepSeek / OpenAI 均可）

## 5 步上手

### 1. 克隆项目

```bash
git clone <本仓库地址>
cd everos-memory-admin
```

### 2. 复制源码 Patch

将 `src/` 下文件复制到你的 EverOS 源码目录：

```bash
cp -r src/everos/ <你的EverOS路径>/src/everos/
```

### 3. 运行安装向导

```bash
python install.py
```

向导会引导你完成：
- ✅ 检查 EverOS 服务
- ✅ 初始化项目空间
- ✅ 创建 memory-admin
- ✅ 授权全局视角
- ✅ 创建第一个业务 Agent

### 4. 验证

```bash
# 查看项目总览
python scripts/project_status.py

# 执行记忆治理
python scripts/governance_exec.py
```

### 5. 在你的 Agent 中使用

将 `agents/memory-admin/SKILL.md` 安装到 Codex/WorkBuddy 的 Skill 目录。

然后对你的 Agent 说：
- "执行记忆巡检" → 自动巡检
- "新建一个 Agent" → 交互创建
- "新建项目" → 一键搭项目

## 术语说明

| 术语 | 含义 |
|---|---|
| user 轨 | 你的个人对话记忆（episode、atomic_fact） |
| agent 轨 | 每个 AI Agent 的任务执行记忆（agent_case、agent_skill） |
| 项目共享知识 | memory-admin 合并去重后的精华，所有 agent 可检索 |
| 巡检 | memory-admin 定期扫描所有 agent 记忆的健康状态 |
| project_insight | 多条 agent_case 合并后的产物 |
| 审计链 | 每条治理操作的可追溯记录（操作前/后状态 + 回滚方式） |
